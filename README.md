# TripPrice Android 📱

A mobile application designed for travelers and expats to easily convert currencies and compare grocery basket prices between different countries in real-time.

## ✨ Key Features
* **Smart Currency Converter:** Fast conversion with up-to-date exchange rates.
* **Grocery Basket Comparison:** Compare costs of essential products worldwide.
* **Offline Mode:** Access cached price data on the go.
* **User-Friendly UI:** Clean, modern, and adaptive interface.
